01 Executive Technical Summary (প্রকল্প পরিচিতি ও সারসংক্ষেপ)

This technical document serves as the master engineering blueprint for Abdullah Karif Shahjada's interactive 3D portfolio. A cutting-edge WebGL 2.0 application combining an isometric 3D developer studio with an authentic retro desktop operating system (Windows 98/2000 style). The outer room is rendered on a hardware-accelerated WebGL canvas, while the internal CRT monitor utilizes Three.js CSS3DRenderer with matrix3d perspective projections to host a fully interactive, reactive TypeScript application.

03 3D Graphics Engine & Environment Design (থ্রিডি ডিজাইন ও স্পেশাল ইফেক্টস)

1. The 3D Room & Light Baking Architecture (রুম ও বেকিং প্রযুক্তি)
Blender + Three.js
Technical Mechanics
Standard real-time shadows in WebGL require heavy shadow maps and multi-pass rendering, causing severe frame drops on laptops and integrated GPUs. To achieve silky-smooth 60 FPS, all Global Illumination (GI), ambient occlusion, and soft lighting were pre-baked in Blender Cycles into high-resolution texture atlases (room.jpg). The meshes are rendered in Three.js using lightweight MeshBasicMaterial, reducing draw-call overhead to under 2ms per frame.
বাংলায় সহজ ব্যাখ্যা
সাধারণত ব্রাউজারে রিয়েল-টাইম লাইট ও ছায়া ক্যালকুলেট করলে কম্পিউটার স্লো বা হ্যাং হয়ে যায়। তাই ব্লেন্ডার (Blender Cycles) সফটওয়্যার দিয়ে রুমের সমস্ত লাইটিং ও শ্যাডো আগে থেকেই ছবির মতো টেক্সচারে "বেক (Bake)" করে নেওয়া হয়েছে। ফলে ব্রাউজারকে লাইটের ভারী হিসেব করতে হয় না এবং যেকোনো নরমাল ল্যাপটপ বা মোবাইলেও এটি মাখনের মতো ৬০ FPS স্পিডে চলে।
2. Coffee Mug & Procedural GPU Steam Shader (কফি ও ধোঁয়ার শেডার)
Custom GLSL
Technical Mechanics
The hot coffee steam is NOT a static GIF or expensive particle system. It is generated mathematically in real-time on the GPU using custom GLSL shaders (coffee/fragment.glsl & coffee/vertex.glsl). A vertical plane above the ceramic mug runs Perlin/Simplex noise algorithms parameterized by uniform uTime, organically distorting texture UVs to simulate rising atmospheric vapor at zero CPU cost.
বাংলায় সহজ ব্যাখ্যা
কফি মগের উপর যে ধোঁয়া উঠছে, তা কোনো সাধারণ ছবি বা ভিডিও নয়। এটি জিপিইউ (GPU)-র ভেতরে সরাসরি GLSL ম্যাথমেটিকাল কোডিং দিয়ে তৈরি করা হয়েছে। গণিতের পার্লিন নয়েজ (Perlin Noise) ও টাইমিং অ্যালগরিদম ব্যবহার করে ধোঁয়াটা প্রাকৃতিক বাতাসের মতো হেলেদুলে উপর দিকে ওঠে, যা দেখতে অত্যন্ত রিয়েলিস্টিক এবং প্রসেসরের কোনো ক্ষতি করে না।
3. Desk, CRT Monitor & Raycasting Alignment (কম্পিউটার টেবিল ও ইন্টারেকশন)
Raycasting + GSAP
Technical Mechanics
The wooden desk, keyboard, mouse, and CRT monitor are arranged in an isometric perspective. To enable natural mouse clicking on 3D objects, a Three.js Raycaster projects a 2D mouse coordinate vector into 3D clip space. When the ray intersects the computer monitor mesh, it triggers a choreographed GSAP camera tween with custom cubic bezier curves, seamlessly zooming the viewport directly into the screen surface.
বাংলায় সহজ ব্যাখ্যা
টেবিল, কীবোর্ড ও মনিটর একটি দৃষ্টিনন্দন আইসোমেট্রিক অ্যাঙ্গেলে সাজানো। থ্রিডি রেইকাস্টিং (Raycasting) প্রযুক্তির মাধ্যমে মাউস ঠিক কোন অবজেক্টের উপর আছে তা ব্রাউজার বুঝতে পারে। মনিটরে ক্লিক করার সাথে সাথে GSAP অ্যানিমেশন ক্যামেরাকে মাখনের মতো মসৃণভাবে সোজা কম্পিউটারের স্ক্রিনের মধ্যে জুম করিয়ে দেয়।

04 The Retro OS & Inner Computer Architecture (কম্পিউটারের ভেতরের রেট্রো ওএস)

1. Three.js CSS3DRenderer & Matrix3D Perspective (থ্রিডি স্ক্রিন প্রজেকশন)
CSS3D Engine
Technical Mechanics
Standard WebGL can only render 2D textures or canvas bitmaps, which cannot accept selectable text, links, or native inputs. This architecture solves that limitation using Three.js CSS3DRenderer. A real HTML5 DOM <iframe> is transformed via CSS matrix3d(...) calculations to align pixel-perfectly with the 3D CRT glass geometry, allowing fully functional web browsing inside the 3D room.
বাংলায় সহজ ব্যাখ্যা
থ্রিডি ক্যানভাসের ভেতরে সাধারণ ওয়েবপেজের লিংক বা টেক্সট ক্লিক করা যায় না। এই সমস্যা সমাধানের জন্য Three.js-এর CSS3DRenderer ব্যবহার করা হয়েছে। এটি একটি আসল ওয়েবপেজকে (iframe) গণিতিক ম্যাট্রিক্স (matrix3d) দিয়ে ঠিক কম্পিউটারের কাঁচের মনিটরের মাপে ৩৬০ ডিগ্রিতে ফিট করে দেয়, যার ফলে মনিটরের ভেতরের সব বাটন ও উইন্ডো আসল কম্পিউটারের মতোই কাজ করে।
2. React 17 + TypeScript Window Management (উইন্ডো ও ওএস ম্যানেজমেন্ট)
React + Framer Motion
Technical Mechanics
The desktop environment inside the CRT screen is a full Single Page Application (SPA) powered by React 17 and strict TypeScript 4.6.2. It includes a custom virtual Window Manager handling draggable title bars, minimize/maximize state machines, z-index focus layering, taskbar icon synchronization, and React Router v6 navigation.
বাংলায় সহজ ব্যাখ্যা
মনিটরের ভেতরের অপারেটিং সিস্টেমটি রিঅ্যাক্ট (React) এবং টাইপস্ক্রিপ্ট (TypeScript) দিয়ে তৈরি। এতে আসল উইন্ডোজ ৯৮ বা ২০০০-এর মতো যেকোনো উইন্ডো মাউস দিয়ে ধরে টেনে সরানো যায় (Drag), ছোট-বড় করা যায় (Minimize/Maximize) এবং নিচের টাস্কবারে ক্লিক করে সুইচ করা যায়।

05 Audio Foley Architecture & Sound Design (সাউন্ড ও অডিও সিস্টেম)

Mechanical Typing & Ambient Audio Engineering
Web Audio API
Technical Mechanics
Features a bespoke Foley audio soundstage. Keystrokes inside any input field or terminal trigger a randomized selector across 6 distinct mechanical keyboard click samples (key_1.mp3 to key_6.mp3), preventing repetitive audio fatigue. Looping background ambient room tone (cassette tape white noise) runs through a decoupled HTML5 audio element with automatic autoplay unlock listeners.
বাংলায় সহজ ব্যাখ্যা
কম্পিউটারের ভেতরে টাইপ করার সময় যে চমৎকার মেকানিক্যাল কীবোর্ডের সাউন্ড হয়, তার জন্য ৬টি আলাদা আলাদা আসল কীবোর্ড ক্লিকের সাউন্ড ফাইল রাখা হয়েছে। যখনই কোনো বোতাম চাপবেন, প্রতিবার লটারির মতো র‍্যান্ডম একটি সাউন্ড বাজে যাতে কান বিরক্ত না হয়। এছাড়াও ব্যাকগ্রাউন্ডে একটি মৃদু ক্যাসেট নয়েজ চলে যা নব্বই দশকের কম্পিউটারের আসল পরিবেশ তৈরি করে।
